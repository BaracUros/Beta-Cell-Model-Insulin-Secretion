# Beta-Cell-Model-Insulin-Secretion

This repository contains the C++ source code used for the Beta-Cell-Model-Insulin-Secretion network simulations described in the associated Biophysical Journal manuscript.

## Contents

- `Kuramoto_Izhikevich.cpp` - main C++ simulation source code
- `Kuramoto_Izhikevich.vcxproj` - Visual Studio C++ project file
- `Kuramoto_Izhikevich.vcxproj.filters` - Visual Studio project filters

Generated simulation outputs are not included in this repository.

## Requirements

The code was developed as a C++ project in Microsoft Visual Studio and uses OpenMP.

Required:
- C++ compiler with OpenMP support
- Microsoft Visual Studio or another compatible C++ build environment

## How to run

Open `Kuramoto_Izhikevich.vcxproj` in Visual Studio, build the project, and run the executable.

The main simulation parameters are defined in `Kuramoto_Izhikevich.cpp`.
